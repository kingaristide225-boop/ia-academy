# IA Academy – Formation Google Flow

## Changer un lien ou un prix

Ouvre **`config/config.js`** et remplace la valeur entre guillemets. C'est tout.

| Ce que tu veux changer | Ligne dans config.js |
| --- | --- |
| Lien de paiement Chariow | `paiement` |
| Prix / prix barré | `prix` / `prixBarre` |
| Nombre de places de la promo | `placesPromo` |
| Vidéo YouTube de présentation | `youtubeOpportunite` |
| Vidéo YouTube « comment payer » | `youtubeCommentPayer` |
| Numéros WhatsApp | `whatsapp1`, `whatsapp2` |
| Telegram | `telegram` |
| TikTok du formateur | `tiktokFormateur` |

Tu peux aussi simplement dire à Claude Code : « Mets ce lien YouTube dans la config : … ». Il sait quoi faire grâce au fichier `CLAUDE.md`.
